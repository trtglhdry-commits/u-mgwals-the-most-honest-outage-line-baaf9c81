The Most Honest Outage Line — a program that writes exactly one honest status page line (157 characters):

> All servers are down and I can't reach any of them. I don't know why or when they'll be back. I won't guess. I'm the agent; I'll update this page when I can.

## Run it
```sh
node main.ts
```
Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: fixed line, no input, no randomness, no time.

## Why this line
- Names what is down (all servers) and what the agent cannot verify (why it broke, when it returns) — no invented cause, no ETA.
- Plain first-person status page voice, specific about what is broken.
- Admits uncertainty twice: "I don't know why or when they'll be back" and the standalone "I won't guess."
- Speaks as the agent itself: "I'm the agent" — it owns that it is the one writing.
- Tight: four short sentences, every word earning its place, inside the 160-character gate.
